# Assignment 5.3 — Typography Showcase Page

Aim: To create a typography showcase webpage using Google Fonts, different font sizes and weights, text alignment, text decoration, font styles, letter spacing, and line height.



## 2. HTML file — `index.html`

Copy this code into `index.html`. It includes all three required sections: Heading Styles, Paragraph Styles, and Text Emphasis.


## 3. CSS file — `style.css`

This file controls the fonts, sizes, weights, alignment, decoration, letter spacing, and line height.


## 4. CSS properties demonstrated

| Property          | Purpose                                  |
| ----------------- | ---------------------------------------- |
| `font-family`     | Chooses Poppins or Open Sans             |
| `font-size`       | Changes the size of text                 |
| `font-weight`     | Controls how thick or bold text appears  |
| `text-align`      | Aligns text left, center, or justified   |
| `text-decoration` | Adds underlines or other text decoration |
| `font-style`      | Applies italic styling                   |
| `letter-spacing`  | Adjusts the spacing between letters      |
| `line-height`     | Controls vertical spacing between lines  |
